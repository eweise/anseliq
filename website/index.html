The problem

Reconciliation breaks quietly.

A balance with no explanation

The clearing account is off by a few hundred dollars and nobody can say which payouts, fees or deposits make up the gap.

Exceptions without context

A mismatch lands in a spreadsheet or a ticket, separated from the transactions that caused it and from whoever is meant to fix it.

Fixes with no trail

Write-offs and corrections get edited in place, so months later no one can show what changed, when, or why.

How it works

From raw files to a balance you can explain.

  1. 01

    Ingest every source

    Files are picked up automatically as they arrive, in CSV, BAI2, JSON or fixed-width format, and recorded on a double-entry ledger.

  2. 02

    Match with rules

    Define how two sides relate, one-to-one or one-to-many, and which fields and dates must agree, including offsets like "settles two days later."

  3. 03

    Explain every difference

    Every balance breaks down into unreconciled, in-progress and mismatched amounts. Each mismatch shows what came in, what went out, and what it matched on.

  4. 04

    Resolve with an auditable record

    Write off, unmatch or wait for the missing movement. Each fix posts a ledger entry, closes its exception automatically, and can itself be reversed.

Mismatches, explained

The answer is on the record, not buried in a spreadsheet.

When a payout and its bank deposit don't agree, AnselIQ shows the two totals, the difference, and the exact value they were matched on. The exception that tracks it sits beside the movements, with the actions to resolve it.

  • —Exceptions are raised automatically when something mismatches or a file goes missing.
  • —They close themselves when the underlying problem is fixed.
  • —Assignment, status and discussion live on the exception's own thread.

Capabilities

Built around how money actually moves.

One-to-one and one-to-many

Match a payout to its bank deposit, or a settlement total to the thousands of card clearing records behind it. Partial groups wait for the rest to arrive, then get flagged once they've aged past your limit.

Rules on any field

Match on IDs, references and dates from either side, with fixed values and date windows, and see exactly which values each reconciliation was matched on.

File feeds with a test bench

Set up a CSV, BAI2, JSON or fixed-width feed and try it against a sample file before going live.

Built for scale

Card clearing files run to millions of records, and AnselIQ reconciles millions of them in minutes. If a run is interrupted, it picks up where it left off instead of starting over.

Corrections, never edits

A bad file is reversed, not deleted. Write-offs post adjustment entries so the ledger always shows what happened.

Exceptions that close themselves

Mismatches and missing files resolve automatically when the real fix happens. People handle the judgment calls, with assignment and a discussion thread.
